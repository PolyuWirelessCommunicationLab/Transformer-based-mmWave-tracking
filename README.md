# Transformer-based mmWave Tracking

The code is for the paper: **"m3TrackFormer: Transformer-based mmWave Multi-Target Tracking with lost target re-acquisition capability"**.

---

# Directory Structure
```text
.
├── data/          # store training and testing dataset
├── model state/   # store the well-trained models
├── results/       # store the tracking results for plot
├── utils/       # store useful functions
```
---

# Packages
Python == 3.9.0
torch==2.8.0 
numpy==2.0.2

# Testing Scripts
To test the performance of the model, run: main_single_tracking.py
